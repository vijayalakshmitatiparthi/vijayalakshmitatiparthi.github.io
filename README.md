# Vijayalakshmi Tatiparthi | Mobile Developer Portfolio

Static GitHub Pages portfolio, including anonymized professional experience, independent demos, and preview videos.

## Publish
1. Create a public GitHub repository named `vijayalakshmitatiparthi.github.io`.
2. Upload or push all files in this folder to the repository root on `main`.
3. Go to Settings > Pages > Build and deployment. Select Deploy from a branch, `main`, `/(root)`, and Save.
4. Open https://vijayalakshmitatiparthi.github.io/ after Pages finishes deploying.

Retain the media directory so embedded Helpora and Nourish videos load. Never publish proprietary employer code or confidential client identities.
